# Project instructions

## Visual/art creation — mandatory pre-check

Before any PixelLab generation call (new theme, new pose, new animation,
anything that spends a free generation) or any other significant
visual-design change to this app, read `retro/README.md` and the most
recent dated file in `retro/` (currently
`retro/2026-09-27-pixellab-visual-art.md`) and follow its guideline
checklist. That checklist exists because roughly two-thirds of all
PixelLab spend to date was either wasted (redone) or never shipped —
skipping it repeats known, documented mistakes.

After finishing a visual-creation work stream (a theme, an animation
pass), write a new dated file in `retro/` per the process in
`retro/README.md`, so the next pass starts from an updated checklist
instead of the same one going stale.
